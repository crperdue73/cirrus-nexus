--- FALSE POSITIVES CAUGHT AND FIXED (three, by running the truth) -------
1. First version flagged plains demo-01 SOLVED. It was scanning header
   COMMENTS that quote the intended commands ("# switch: ip addr add ...").
2. After stripping comments it STILL flagged plains demo-01 and
   demo-02-unsolved SOLVED: the same IPs appear in the `instructions:` list,
   which quotes the commands but does not apply them.
3. Fixed by parsing the YAML and scanning ONLY `topology.nodes.*.exec` and
   `startup-config` file bodies. Output then matched every live run.
   (A lint that cries wolf on labs that actually fail cold is worthless --
   each false positive was rejected by running the real thing.)

--- WHY IT MATTERS ------------------------------------------------------
This is the gate I proposed after finding demo-02 grades 5/5 cold. Any future
lab pack can run `python3 tools/lint_lab_pack.py` before shipping; a non-zero
exit means a lab hands the student the answer key.
NOTE: 9 legacy labs report NO-EXPECTED (their graders don't expose an EXPECTED
map), so the lint is blind to them -- not a claim that they are solved.
