WHAT HAPPENS
A lab-definitions YAML that parses fine but whose `topology:` key is a SEQUENCE (or a scalar)
instead of a mapping raises `AttributeError` inside `_discover_labs`, which takes down the whole
`_reload_labs()` pass — not just the offending file.

WHY IT MATTERS (blast radius, stated precisely)
- `_reload_labs` (main.py:612-669) exists because "one bad metadata file must not be able to take the
  product down" (run 222). It validates each lab inside try — but the exception here is raised in
  `_discover_labs`, i.e. BEFORE the per-lab loop, so that guard never sees it.
- Reachable at runtime via `POST /api/labs/reload` (main.py:1799-1812): the route calls
  `_reload_labs()` with no try, so the client gets an unhandled AttributeError — a 500 with no
  "reloaded with skips" body, no named file, and no reload performed.
- Startup: `_reload_labs` is called at import (main.py:392 comment area, module-level call), so the
  same file in the pack means the service does not come up — the exact failure class RUN 222 fixed
  for malformed fields, re-entered through the topology's TYPE instead of its values.
- Related, already recorded: this mirrors the dead `topology unreadable:` guard at main.py:632,
  which can only fire for a non-mapping `topology` — and this crash happens further up, so the
  guard is unreachable for that shape (main.py:632 comment, tools/lint_lab_pack.py ERROR docs).

SCOPE OF THE DEFECT TODAY
- Neither shipping lab is affected: both topologies are mappings; after removing the repro file,
  `_reload_labs()` returns [] and serves demo-01 + demo-02 clean.
- `tools/lint_lab_pack.py` already reports such a lab as ERROR (rc 2) — the lint knows, the backend
  does not. So a contributor is warned, but a box that never runs the lint still dies.

CANDIDATE FIX (NOT APPLIED — behaviour change, Dad's call)
One line at main.py:443-444: coerce and type-check before `.get`, e.g.
    topo = data.get("topology")
    nodes = topo.get("nodes") if isinstance(topo, dict) else None
    nodes = nodes or {}
which returns "" (no aegis/frr node) and lets the per-lab guard name the file instead of the whole
reload dying. Turning that into a named rejection rather than a silent "" is the design question —
same open call as the dead `topology unreadable:` guard.
