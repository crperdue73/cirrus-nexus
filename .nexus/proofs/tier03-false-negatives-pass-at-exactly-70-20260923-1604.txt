The grader is not measuring 'did the student do it'. It is measuring 'did the
student do it AND did our string match survive FRR's normalisation'. Those are
different questions, and only the first one is the lab.

TWO ROOT CAUSES (same bugs as the lab-02 proof, now shown to be threshold-critical):
  BUG B (hostname case): vtysh stores hostnames LOWERCASE. Graders compare the
    capitalised literal 'hostname RTR'/'hostname SW1' -> can NEVER match. Costs
    0.15/0.10 on tier-03; 0.05/0.05 on lab-03. Affected: lab_02, lab_03,
    tier02_crossing, tier03_switch.
  BUG A (IP check): _check_ip runs 'ip -j addr show' first (succeeds), so the
    '||' plain fallback never runs; JSON splits local/prefixlen so the expected
    string (with /prefix) never appears -> 'got none' on a machine that HAS the
    address. Costs 0.25 here.
