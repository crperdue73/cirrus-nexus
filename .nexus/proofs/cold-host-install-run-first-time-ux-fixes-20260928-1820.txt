DEFECT 1 (real, fixed): final summary printed  "Open browser: http://:8000"
  Cause (read the source, not the symptom): line 449 built the URL with
    hostname -I | awk 'if($i !~ /^(172\.|10\.|192\.168\.|127\.)/){print; exit}'
  which EXCLUDES exactly the private ranges a real host has, then prints whatever
  remains -> empty. An operator on a real LAN would be told to open a URL with no
  host in it.
  FIXED: prefer the first non-loopback IPv4; on failure fall back to
  http://localhost:$PORT with a note. Verified in-container: http://172.18.0.1:8000.

DEFECT 2 (real, fixed): "Default labs auto-discovered:" was followed by NOTHING.
  Cause: the loop globbed lab-definitions/*.yml and grepped for an "id:" key. The
  shipped labs are YAML under lab-definitions/<dir>/ with no top-level id: line, so
  the glob matched nothing and the code still printed the heading -> an empty
  promise. (This also corrects run 28's note that the block "enumerates all 9 labs":
  in the shipped layout it enumerated ZERO.)
  FIXED: find -maxdepth 2 -name '*.yml', print each basename, and report the count.
  Verified in-container: both ship labs listed, "(2 lab file(s))".
